# TinyMCE 7 プラグイン

[![TinyMCE 7](https://img.shields.io/badge/TinyMCE-7.x-blue.svg)](https://www.tiny.cloud/tinymce/)
[![MODX Evolution](https://img.shields.io/badge/MODX%20Evolution%20JP-latest-0f7fb3.svg)](https://modx.jp/)

MODX Evolution で最新の TinyMCE エディターを利用できるようにするプラグインです。

> **安定版について**
>
> 現在の安定リリースは `v1.0.1` です。運用環境へ導入する前にテスト環境で動作を確認したうえでご利用ください。

## 特長

* 文字装飾や画像挿入など、管理画面でのリッチテキスト編集をより快適にします。
* 管理画面・フロントエンドの両方で同じエディター体験を実現します。
* MODX Evolution 標準の MCPuk ファイルブラウザーと連携し、画像やファイルを簡単に選択できます。
* 画像をクリック／ダブルクリックすると Cropper.js を使ったトリミング・回転・サイズ変更が行えます。

## 導入手順

1. プラグイン一式をダウンロードします。
2. FTP で MODX Evolution の設置ディレクトリに接続し、`assets/plugins/tinymce7/` フォルダーを作成します。
3. ダウンロードしたファイルをすべて `assets/plugins/tinymce7/` にアップロードします。
4. 管理画面にログインし、**エレメント → プラグイン** を開きます。
5. 「新規プラグイン作成」をクリックし、ソースコード欄に `tinymce.install_base.tpl` の内容を貼り付けるか、該当ファイルを指定します。
6. プラグイン名を「TinyMCE7」など任意に設定し、以下のイベントを関連付けます。

   * `OnRichTextEditorRegister`
   * `OnRichTextEditorInit`
   * `OnInterfaceSettingsRender`
7. 保存後、リソース編集画面でエディターが有効になっていることを確認します。

## 旧 TinyMCE からのアップデート

旧 TinyMCE から上げたサイトでは、グローバル設定とユーザー設定の使用エディターが `TinyMCE` なら、アップデート時に `TinyMCE7` に読み替えます。アップデーターで TinyMCE 7 のチェックを外して旧 TinyMCE を残すときは、アップデート後に使用エディターを選び直してください。

## カスタマイズ

* **ツールバー設定**: グローバル設定またはユーザー設定の「TinyMCE7 ツールバー構成」から、最小／省スペース／TinyMCE 3 風（既定）／すべての各構成を選択できます。「省スペース」は、見出し・太字・揃えなどを、ツールバーの「書式」（「CSSスタイルセレクタ」のクラスもここに並ぶ）から選ぶ構成です。そのぶんボタンを減らした、短いツールバーです。
* **画像のキャプション**: どの構成でも、画像のダイアログの「キャプションの表示」をオンにすると、画像が `<figure class="image"><img …><figcaption>…</figcaption></figure>` で保存されます。キャプションの仮の文字「Caption」（英語）が入るので、書き換えてください（そのまま保存すると公開側にも出ます）。公開側の見た目は、サイトの CSS で `figure.image` と `figure.image > figcaption` に書いてください（例: `figure.image { display: table; margin: 1em auto; } figure.image > figcaption { display: table-caption; caption-side: bottom; text-align: center; }`。詳しくは [TECHNICAL.md](docs/TECHNICAL.md)）。
* **リンクの操作の帯**: リンクの中にカーソルを置くと、リンクの上に URL の入力欄と、反映・リンクの削除・リンクを開くのボタンが並ぶ小さなツールバーが出ます。クラス・Rel・開き方を変えるときは、ツールバーのリンクのボタン（Ctrl+K）でダイアログを開きます。
* **メニューバー表示**: 必要に応じてメニューバーを表示・非表示に切り替えられます。
* **編集欄の body の id・クラス**: 編集欄の `<body>` に付ける id とクラスを指定できます。公開側で本文を囲む要素（例: `<div id="center">`）と同じ id・クラスを入れると、「CSSファイルへのパス」の CSS をそのまま編集欄にも効かせられます。サイト共通の設定で、システム設定画面でだけ変更できます。旧 TinyMCE プラグインの「Custom Parameters」にある `body_id`・`body_class` は、アップデート時に引き継ぎます。それ以外の値と、`body_id`・`body_class` でも空の値・サイトのタグ（`[*…*]` など）を含む値・文字列でない値は引き継がず、そのキー名をシステムログに警告として残します。
* **CSSスタイルセレクタ**: 「表示名=クラス名;表示名2=クラス名2」の形式で、ツールバーの「書式」から選べる CSS クラスを追加できます。同じクラスは、リンクの挿入・編集の画面の「クラス」からも選べます。「表示名=a.クラス名」のように要素名 `a`・`img`・`table` を前に付けると、その要素にだけ付けるクラス（ボタン風のリンク、画像の回り込み、表の縞模様など）になり、リンク・画像・表のダイアログの「クラス」から選べ、「書式」ではその要素を選んだときだけ使えます（例：`ボタン=a.btn;回り込み左=img.float-left;縞模様=table.striped`）。要素名の無い項目は画像・表のダイアログの候補に入らないので、画像のダイアログの「クラス」に出したいクラスは `img.` を付けて書いてください。複数のクラスは `a.btn.primary` のように `.` でつなぎます。要素名の無い項目は、リンクを選んで当てても、段落の中身がリンクだけだと `<p>` にクラスが付くので、リンクに付けたいクラスは `a.` で書いてください。空のときは、レガシー・フルの構成では「CSSファイルへのパス」の CSS にあるクラスがすべて「書式」に並ぶので、クラスの多い CSS を使うサイトは、使うクラスをここに書いて一覧を絞ってください。サイト共通の設定で、システム設定画面でだけ変更できます。旧 TinyMCE プラグインの同名設定は自動で引き継ぎます。クラスの見た目は「CSSファイルへのパス」で読み込む CSS に書いてください。
* **リンクの rel**: 「表示名=値;表示名2=値2」の形式で、リンクの挿入・編集の画面の「Rel」から選べる値を指定できます（例: `画像を拡大=lightbox`。旧 TinyMCE の「ページからターゲットの関係」にあたります）。空なら欄は出ません。サイト共通の設定で、システム設定画面でだけ変更できます。
* **ひな形の挿入**: システム設定の「ひな形」にリソースID・チャンク名・チャンクのカテゴリを指定すると、ツールバーの「ひな形の挿入」ボタンや「挿入」メニューから、その本文を一覧で選んで挿入できます。TinyMCE 7 ではオープンソース版の template プラグインが廃止されたため、その代わりとなる本プラグイン独自の機能です。指定が無いときはボタンを表示しません。
* **TinyMCE 本体の読み込み元**: デフォルトは CDN (`https://cdn.jsdelivr.net/npm/tinymce@7/tinymce.min.js`) です。ローカルで使いたい場合は公式パッケージの `tinymce/` を `assets/plugins/tinymce7/tinymce/` に配置し、設定に `"tinymce_use_local": true` を追加してください。CDN・ローカル問わず別の URL を使う場合は `config/manager.json` や `config/frontend.json` に `"tinymce_script_url"` を指定します。
* **言語ファイル**: 日本語などの UI 言語はローカルの `assets/plugins/tinymce7/tinymce/js/tinymce/langs/`（または `assets/plugins/tinymce7/langs/`）に置いた公式 `langs/*.js` を読み込みます。TinyMCE 公式配布の言語パックをダウンロードして配置してください（CDN フォールバックはありません）。

詳細な設定や開発者向け情報は [TECHNICAL.md](docs/TECHNICAL.md) を参照してください。
