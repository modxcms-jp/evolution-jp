# リクエスト値の取り出し方

ブラウザが送ってくる値（URL のクエリの GET と、フォームの送信内容の POST）の取り出し方の決まり。`$_GET` / `$_POST` / `$_REQUEST` には直接触らず、`manager/includes/helpers.php` のヘルパーを通す。

## 2 種類のヘルパー

| 種類 | 関数 | 返すもの |
| --- | --- | --- |
| 生の値 | `getv()` / `postv()` / `anyv()` | 値を変換せずに返す。キーを省略すると全件の配列 |
| 型つきの値 | `*_intvar()` / `*_strvar()` / `*_boolvar()` / `*_choicevar()` / `*_idsvar()` | 決まった型の値だけ。それ以外は既定値 |

型が決まっている値は、型つきのヘルパーで取り出す。生の値を取り出したあとに `(int)`・`intval()`・`preg_match()`・`is_numeric()` などで自分で確かめる書き方は使わない（0 や負の数が意味を持つ値は、型つきでまだ読めないので除く。下の「`*_intvar()` の範囲」を参照）。リクエストは配列や空の値も送れるので、生の値を文字列関数や `count()` に直接渡すと、PHP 8 以降で警告や TypeError になる。

## 受け取り元の選び方

接頭辞で受け取り元を選ぶ。その処理が実際に呼ばれる方法に合わせる。

| 接頭辞 | 受け取り元 | 生の値 |
| --- | --- | --- |
| `get_` | GET だけ | `getv()` |
| `post_` | POST だけ | `postv()` |
| `request_` | GET と POST の両方 | `anyv()` |

`request_` は、GET と POST の両方で呼ばれる処理だけに使う。変換の本体は受け取り元に依らない `to_*()` にあり、`get_` などは `to_*(getv($key), ...)` のように呼ぶだけ。

## 型つきヘルパーの戻り値

`*` は `get_` / `post_` / `request_` のいずれか。

| 関数 | 戻り値 |
| --- | --- |
| `*_intvar($key)` | 正の整数なら int。それ以外（数字以外を含む・0・負数・配列・空）は 0 |
| `*_strvar($key, $default = '')` | 空でない文字列ならそのまま。それ以外（無い・空文字・配列）は `$default` |
| `*_boolvar($key, $default = false)` | `'1'`・`'on'`・`'true'`・`'yes'` なら true、`'0'`・`'off'`・`'false'`・`'no'` なら false。それ以外は `$default` |
| `*_choicevar($key, array $choices, $default)` | 文字列として `$choices` のいずれかと一致したら、その要素（`$choices` の側の型）。それ以外は `$default` |
| `*_idsvar($key)` | id の int の配列。配列でもカンマ区切りの文字列でも受ける（文字列は、カンマで分けた各要素の前後の空白を除く）。各要素を `to_intvar()` に通して 0 を除き、重複を除く。読めない要素は黙って捨てる。それ以外は `[]` |

### `*_intvar()` の範囲

0 や負の数が意味を持つ値（並びのずれなど）は、型つきのヘルパーでまだ読めない。それまでは今の書き方を残し、置き換えの途中で `*_numvar()` を足すかを決める。

### `*_idsvar()` の注意

- 読めない要素は黙って捨てる。1 つでも不正なら全体を拒否したい処理（移動・削除など。例: `manager/processors/document/move_document.processor.php`）は、`*_idsvar()` に置き換えずに今の書き方を残すか、元の要素数と戻り値の要素数を比べて確かめる。

### 空白と大文字小文字

- 大文字小文字を無視するのは `*_boolvar()` だけ。
- 前後の空白を除くのは `*_boolvar()` と、`*_idsvar()` の文字列の場合だけ。`*_idsvar()` は文字列で受けたとき、カンマで分けた各要素の前後の空白を除く（`' 3, 4 '` は `[3, 4]`、カンマを含まない `' 3 '` も `[3]`）。配列で受けた要素の空白は除かない（`id[]=%203` は読めない要素として捨てる）。
- それ以外のヘルパーは、空白も大文字小文字もそのまま扱う。

## 空の値の扱い

- 生の値は、キーがあれば空文字（`?k=`）もそのまま返す。既定値はキーが無いときだけ使う。
- 型つきは、空も形式違いも既定値にする。
- `getv()` / `postv()` / `anyv()` は同じ動きで、空の値を「無い」とはみなさない。以前の `getv()` にあった、空の値を既定値（省いたときは `null`）として返す特例はやめた。空の値を無いものとして扱いたいときは、型つきのヘルパーを使う。

## 置き換えの表

| 今の書き方 | 置き換え先 |
| --- | --- |
| `preg_match('@^[1-9][0-9]*$@', getv('id')) ...` | `get_intvar('id')`（0 なら無い扱い） |
| `(int) postv('parent')` / `intval(anyv('x'))` | `post_intvar('parent')` など |
| `getv('force', 0)` を真偽として使う | `get_boolvar('force')` |
| `getv('period', 'latest')` を選択肢として使う | `get_choicevar('period', [...], 'latest')` |
| `anyv('depid')` を id の配列として使う | `request_idsvar('depid')` |
| `trim(postv('q'))` / `strtolower(getv('x'))` | `trim(post_strvar('q'))` など |

注意: `getv('force', 0)` のように真偽として使っている値を `*_boolvar()` に置き換える前に、送られる値が `*_boolvar()` の戻り値の欄にある 8 つの語に収まるか確かめる。一覧に無い値（チェックボックスの独自の `value` など）は、今は真になるが、置き換え後は既定値になる。

## 生の値のまま残してよい形

- 文字列として厳密に比べるだけのもの（`postv('mode') === 'save'`）
- 値を使わず、送られたかどうか（真偽）だけを見るもの（`if (getv('submitok'))`）。送信ボタンの `value` が文言のときなど、`*_boolvar()` の 8 つの語に収まらない値はこちら
- `db()->escape()` に渡して保存するもので、配列が来たときの扱いを呼び出し側が決めているもの
  - 残してよい例: `is_array()` で先に弾いてから `db()->escape(postv('x'))` に渡す。配列のまま `db()->escape($fields)` で insert に渡す
  - 取り出し方を変える例: `sprintf("…'%s'", db()->escape(getv('x')))` のように SQL の文の中に埋め込むものは、配列が来ると警告になるので `*_strvar()` で取り出す
- 配列だけを受ける項目（`docgroups[]` のようなチェックボックスの組）。配列でないときは `[]` として扱う（`is_array()` で確かめる）
- 空で送ることに意味がある検索語など（例: モジュール一覧の `search`。空で送ると検索語を消す）は、生の値で受けて `is_string()` で確かめる。`*_strvar()` だと空が既定値になるため
- 文字列と配列のどちらも正しい値になる項目（テンプレート変数の値など）。生の値のまま受け、受ける側で型ごとに扱いを決める

`a` などで権限を分ける判定は、型つきで読み、当てはまらない値は拒否する（`switch` の `default` でエラー）。

`hsc()` などで出力するものは、生の値のまま渡さない。配列が来ると PHP 8 以降で警告や TypeError になるので、`*_strvar()` で取り出す（`hsc(get_strvar('q'))`）。選択状態を決めるための `==` の比較も、比べる値の型に合わせて `*_intvar()` / `*_strvar()` で取り出す。数値の比較は、値が無いときの 0 が 0 の行に一致しないよう、`get_intvar('x') && (int)$row['x'] === get_intvar('x')` の形にする。

`evo()->input_get()` / `input_post()` / `input_any()` は、`getv()` / `postv()` / `anyv()` と同じ生の値を返す。同じ規則で読み、`get_` / `post_` / `request_` の型つきヘルパーに置き換える。
